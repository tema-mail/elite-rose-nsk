# Elite Rose (Новосибирск) – сайт цветочного магазина

Второй сайт на базе шаблона Milovini (`~/Sites/milovini-samara`): тот же код каталога, корзины, избранного
и страницы заказа, своя стилистика и данные Elite Rose (сообщество VK vk.ru/elite_rose_nsk).
Замысел – `docs/ЗАМЫСЕЛ.md`, решения – `docs/РЕШЕНИЯ.md`, долги – `docs/ТЕХДОЛГ.md`.

## Стек и запуск
- Astro 7 (статика), острова Preact, состояние – `@preact/signals` (`src/lib/store.ts`).
- `npm run dev`, `npm run build`. Просмотр `dist/` – `python3 -m http.server` (превью Astro 7 – общий демон, может отдать чужой проект).
- `npm run data` – пересобрать товары из `data-src/vk-products.json` (снято с раздела «Товары» VK) в `src/data/*.json` и фото в `public/img/p`.
- Публикация: GitHub Pages (`tema-mail/elite-rose-nsk`), `.github/workflows/pages.yml`, закрыто noindex.

## Структура
- Страницы: главная, `/catalog` (разделы – `?part=<id>`), карточки `/catalog/tproduct/<id>-<slug>`, `/order`, `/favorites`, `/thanks`.
- Контакты и навигация – `src/lib/site.ts`; разделы – `scripts/import-vk.mjs` (по названию товара).
- Заявки и заказы – `src/lib/forms.ts`: собираются в текст и уходят в переписку VK (своего приёмника нет).

## Соглашения
- Тире только короткое «–», длинное (U+2014) не ставить нигде.
- Каталог: на телефоне две карточки в ряд; фильтр – чип «Все» первым, выбор прячет лишнее.
- Внутренние ссылки и картинки – только через `u()` из `src/lib/url.ts`.
- Данные компании – только подтверждённые источником (VK). Чего нет – не выдумывать (часы закрытия, отзывы, реквизиты).

## Правила работы
- Файл больше 800 строк не дописывать, а выносить новый модуль.
- Делать только то, о чём просили. Никаких попутных улучшений и лишних файлов.
- После каждого рабочего шага – коммит.
- Перед правкой прочитать те места, которых она касается, а не догадываться.
- Задача трогает больше трёх файлов кода – остановиться и предложить разбить.
- Чего не знаешь – спросить, а не подставить заглушку и не выдумать.
- Решение, записанное только в комментарии, не считается внедрённым: выбор
  модели, провайдера или настройки живёт в константе, которую код читает.
- Владелец сообщает о сбоях словами в чате и в файлы сам не пишет – записывать за ним.
- После задачи – строка в `docs/РЕШЕНИЯ.md`, найденный долг – в `docs/ТЕХДОЛГ.md`.
